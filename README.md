# 🎬 용산 IMAX 취소표 알리미

**CGV 용산아이파크몰 IMAX의 원하는 영화·날짜·좌석 조건을 등록하고, 조건에 맞는 좌석이 다시 열리면 Discord로 알려주는 개인 프로젝트입니다.**

</div>

<br>

## 📢 안내

현재는 **용산아이파크몰 IMAX**를 중심으로 운영하는 것을 목표로 합니다.

사용자는 별도 프로그램 설치나 Python 실행 없이 **Discord 서버 초대 링크로 입장한 뒤 메뉴만 선택**해서 사용할 수 있도록 설계했습니다.

> Discord 초대 링크: **배포 후 여기에 추가 예정**

<br>

## 🔔 알림 받는 방법

### 1. Discord 앱을 설치하세요.

Discord 앱 설치 후 알림을 허용해주세요.

### 2. 위 초대 링크로 서버에 입장하세요.

별도의 프로그램 설치, GitHub clone, Bot Token 설정은 필요하지 않습니다.

### 3. Discord에서 `/setup`을 실행하세요.

기본 설정을 한 번 저장합니다.

- 👥 관람 인원
- 💺 좌석 허용 범위
- 👫 연석 조건

기본값은 아래와 같습니다.

> **2명 / 연석 우선 / 웬만하면 OK**

### 4. `/watch_menu`를 실행하세요.

```text
영화 선택
   ↓
날짜 선택
   ↓
감시 시작
```

원하는 영화와 날짜를 선택하면 이후 조건에 맞는 취소표가 발견될 때 Discord 알림을 받습니다.

<br>

## 💺 좌석 범위

좌석 번호를 몇 번부터 몇 번까지라고 고정하지 않고, 실제 좌석 배치에서의 **앞뒤·좌우 위치**를 기준으로 판단하도록 설계했습니다.

| 설정 | 기준 |
|---|---|
| 🎯 명당만 | 중앙 중간부 위주 |
| 👍 좋은 자리 | 중앙을 기준으로 조금 넓게 |
| 🙂 웬만하면 OK | 너무 앞쪽·극단 사이드만 제외 |
| 🌐 최대한 넓게 | 극단적인 좌석만 일부 제외 |

<br>

## 👫 연석 조건

| 설정 | 의미 |
|---|---|
| 전원 연석 | 선택한 인원 전부 붙어 있어야 알림 |
| 최소 2연석 | 최소 두 자리 이상 붙어 있으면 알림 |
| 연석 우선 | 연석을 우선 추천하되 조건에 따라 개별 좌석도 허용 |
| 상관없음 | 붙어 있지 않아도 알림 |

<br>

## 🎞️ 영화마다 조건을 다르게 설정할 수 있나요?

가능합니다.

설정 우선순위는 아래와 같습니다.

```text
내 기본 설정
   ↓
영화별 설정
   ↓
특정 영화 + 특정 날짜 설정
```

예를 들어:

```text
기본
2명 / 연석 우선 / 웬만하면 OK

영화 A
3명 / 전원 연석 / 좋은 자리

영화 A - 8월 23일
1명 / 상관없음 / 명당만
```

처럼 사용할 수 있습니다.

<br>

## 📱 주요 명령어

| 명령어 | 기능 |
|---|---|
| `/setup` | 내 기본 좌석 조건 설정 |
| `/watch_menu` | 영화 → 날짜를 선택해 감시 시작 |
| `/watch` | 특정 영화·날짜에 상세 조건을 직접 설정 |
| `/movie_override` | 특정 영화의 기본 조건 변경 |
| `/watches` | 현재 감시 중인 목록 확인 |
| `/pause` | 특정 감시 일시정지 |
| `/resume` | 감시 재개 |

<br>

## 🔔 알림 예시

```text
🚨 용산 IMAX 취소표 발견

🎬 영화명
📅 2026-08-23
🕒 19:40
👥 2명
💺 H23, H24
✨ 웬만하면 OK / 2연석

CGV 앱에서 바로 확인하세요.
```

같은 좌석이 계속 비어 있는 동안 반복해서 알림을 보내지 않고,

```text
빈 좌석 발견 → 알림
계속 빈 상태 → 추가 알림 없음
판매 완료 → 상태 초기화
다시 취소표 발생 → 다시 알림
```

방식으로 동작합니다.

## ⚠️ 꼭 확인해주세요

- 이 프로젝트는 **자동 예매 프로그램이 아닙니다.**
- 좌석 자동 선택, 좌석 선점, 결제 자동화 기능을 제공하지 않습니다.
- CGV의 접근 제한이나 보안 절차를 우회하지 않습니다.
- 서비스 안정성을 위해 과도한 요청을 보내지 않도록 요청 주기와 백오프 정책을 적용합니다.
- CGV의 서비스 변경에 따라 알림이 일시적으로 동작하지 않을 수 있습니다.
- 이 프로젝트는 CGV와 공식적으로 제휴된 서비스가 아닙니다.
